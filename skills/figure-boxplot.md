# Skill: figure-boxplot

When the user asks for boxplots / stats figures:

1. Reuse helpers in `stats_figures/boxplots/` and themes in `stats_figures/templates/`.
2. Prefer tidy input tables (CSV) with explicit group columns.
3. Report the test used (Wilcoxon / t-test / ANOVA) next to the plotting code.
4. Save scripts, not giant PDFs, unless the user asks to commit a figure.
5. Never modify shared lab repositories.
