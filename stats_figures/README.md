# Statistics & figures

Publication-oriented plotting and stats helpers.

| Subfolder | Use |
|-----------|-----|
| `boxplots/` | Box / violin / jitter plot recipes (ggplot2, MATLAB, seaborn, …) |
| `templates/` | Shared theme, color palettes, save-figure helpers |
